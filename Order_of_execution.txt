=========================================================
DeepStack-SDP : Project Execution Order
=========================================================

Project:
DeepStack-SDP
(Deep Feature Stacked Ensemble Framework for Software Defect Prediction)

=========================================================
PHASE 0 : Setup
=========================================================

1. Clone Repository

git clone <repository_url>

2. Create Environment

python -m venv venv

3. Activate Environment

Windows:
venv\Scripts\activate

Linux/macOS:
source venv/bin/activate

4. Install Dependencies

pip install -r requirements.txt
